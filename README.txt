《剪煞 The Snip》網站原型 — PNG 圖片版
========================================

開啟方式
1. 將 ZIP 解壓縮。
2. 保持 index.html、styles.css、script.js 與 assets 資料夾在同一層。
3. 將 PNG 圖片放入 assets/images/，檔名請依下方清單命名。
4. 使用 Chrome / Edge 開啟 index.html。

PNG 圖片清單（全部放在 assets/images/）
----------------------------------------
網站主視覺：
- hero_bg.png              首頁主視覺背景（建議 1920×1080，場景截圖）
- gameplay_main.png        玩法區大圖（建議 1200×900，遊戲實機截圖）

章節圖片：
- chapter_prologue.png     序章／主角調查空間
- chapter_temple.png       第一幕／廢墟老廟
- chapter_tunnel.png       第二幕／地下坑道

調查物件圖片：
- evidence_camera.png      相機
- evidence_map.png         老廟手繪平面圖
- evidence_bagua.png       陰陽八卦盤
- evidence_flashlight.png  手電筒
- evidence_matches.png     火柴盒
- evidence_tape.png        錄音帶
- evidence_recorder.png    可攜式錄音機
- evidence_film.png        底片

goods 周邊圖片：
- goods_bookmark.png       符咒書籤
- goods_amulet.png         平安符袋／御守
- goods_notebook.png       調查筆記本

識別圖：
- logo_mark.png            團隊／遊戲標誌（透明背景 PNG）

圖片格式建議
----------------------------------------
- 場景圖：可用一般 PNG，版面會以 cover 裁切填滿。
- 去背商品、道具：使用透明背景 PNG，版面會以 contain 完整呈現。
- 建議檔名使用英文、數字及底線，避免空格與特殊符號。
- 若暫時沒有某張圖片，該位置可能顯示空白；補上同名圖片即可，不需要修改程式碼。

網站功能
----------------------------------------
- 手機版導覽選單
- 滑鼠跟隨手電筒光束，可切換開關
- 調查物件切換（同步切換圖片與文字）
- 章節圖片與周邊商品 PNG 顯示
- YouTube 實機影片嵌入
